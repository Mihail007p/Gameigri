## 4. Решения и почему так

| Решение | Причина |
|---|---|
| Не использовать личный PAT в чате | Токен остаётся в истории переписки. Выбран официальный **Device Flow**: код вводится владельцем в своём профиле, пароль никому не передаётся |
| Токен в `/tmp`, а файлы проекта в `/home/user` | `/tmp` не попадает в снапшот рабочей области и в архив → секрет не утекает в файлы проекта |
| Проект без сборки и зависимостей | Задача была «чистый репозиторий + чистый HTML»; чем меньше деталей, тем проще продолжать |
| Журнал хранится в репозитории, а не только в чате | Репозиторий доступен из любой сессии и из любой машины; чат со временем теряет контекст |

## 5. Как продолжить в другом чате (пошагово)

1. Откройте репозиторий: https://github.com/Mihail007p/Gameigri
2. Прочитайте `PROGRESS.md` (этот файл) и `AGENTS.md`.
3. Вставьте в новый чат готовый текст:

```
Проект: Gameigri — https://github.com/Mihail007p/Gameigri
Прочитай PROGRESS.md и AGENTS.md из этого репозитория
(например: https://raw.githubusercontent.com/Mihail007p/Gameigri/main/PROGRESS.md),
пойми текущее состояние и продолжи работу. Задача: <что нужно сделать>.
Все решения фиксируй в PROGRESS.md и коммить.
```

4. Если нужно залить изменения на GitHub — запустите `bash tools/gh_push.sh "сообщение коммита"` и введите выданный одноразовый код на https://github.com/login/device (15 секунд).

**Важно про среду:** в новой песочнице `gh` CLI может отсутствовать, интернета или git может не быть — скрипт `tools/gh_push.sh` сам скачает `gh` при первом запуске. Проверка связи: `curl -sS -o /dev/null -w '%{http_code}' https://api.github.com` → должно вернуть `200`.

1. Добавить строку в «Хронологию изменений»: дата/время, что сделано, хеш коммита.
