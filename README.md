# Gameigri

Чистый стартовый репозиторий: минимальный HTML + git, опубликован на GitHub.

🔗 **Репозиторий:** https://github.com/Mihail007p/Gameigri

## Документация проекта

| Файл | Зачем |
|---|---|
| [`PROGRESS.md`](PROGRESS.md) | **Журнал прогресса**: что сделано, текущее состояние, бэклог, хронология изменений |
| [`AGENTS.md`](AGENTS.md) | Правила работы для AI-агента / новой сессии: как продолжать проект |
| `README.md` | Этот файл — краткое описание и запуск |

> Потерялся контекст в чате? Откройте `PROGRESS.md` — там всё, что нужно, чтобы продолжить работу.

## Структура

```
Gameigri/
├── index.html          # чистый HTML5-каркас
├── README.md
├── PROGRESS.md         # журнал прогресса
├── AGENTS.md           # инструкции для агента
├── .gitignore
└── tools/
    └── gh_push.sh      # публикация изменений на GitHub (авторизация по одноразовому коду)
```

## Локальный запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Публикация изменений

```bash
bash tools/gh_push.sh "feat: описание изменения"
```

Скрипт сам скачает `gh` CLI при необходимости, выдаст одноразовый код для входа
(https://github.com/login/device), закоммитит и запушит `main`. Пароль не требуется,
токен удаляется после пуша.

## Правило ведения журнала

При каждом изменении — запись в `PROGRESS.md`: дата, что сделано, хеш коммита,
плюс обновление раздела «Текущее состояние». Журнал коммитится вместе с изменением.
