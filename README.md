# Gameigri — гонки 🏁

Аркадные гонки в одном HTML-файле: машина едет по трассе, объезжает трафик, счёт — пройденная дистанция.
**Ноль зависимостей, ноль сборки** — открывается двойным кликом.

🔗 **Репозиторий:** https://github.com/Mihail007p/Gameigri

## Играть

Откройте `index.html` в браузере. Или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

### Управление

| Действие | Клавиши | Тач |
|---|---|---|
| Руль | ← → или A / D | кнопки ◀ ▶ |
| Газ | ↑ или W | кнопка ▲ |
| Тормоз | ↓ или S | кнопка ▼ |
| Пауза | P / Esc | — |
| Старт / рестарт | Enter | клик по полю |

Дистанция растёт сама — удерживайте скорость и объезжайте трафик. Чем дальше, тем плотнее поток
и выше максимальная скорость. Рекорд сохраняется в браузере.

## Тесты

```bash
node tools/test_game.js     # локально: 17 проверок
```

То же самое автоматически запускается на GitHub Actions при каждом push — вкладка **Actions**.

17 проверок логики без браузера: разгон, руль и границы, трафик и утечки, столкновения и рестарт,
пауза, рекорд, а также баланс сложности (расчётливый бот должен уезжать далеко).
Стенд сам вытаскивает скрипт из `index.html` и прокручивает кадры вручную — ничего устанавливать не нужно.

## Структура

```
Gameigri/
├── index.html          # игра: вёрстка, стили, логика (Canvas 2D)
├── README.md
├── PROGRESS.md         # журнал прогресса
├── AGENTS.md           # инструкции для агента
├── .gitignore
├── .github/workflows/
│   └── tests.yml       # CI: автотесты на каждый push
└── tools/
    ├── test_game.js    # автотесты логики и баланса
    ├── restore.sh      # восстановить проект из GitHub в пустой среде
    ├── gh_push.sh      # commit + push (+ --pages)
    └── deploy_new.sh   # создать новый репозиторий из папки
```

## Восстановление в новой среде

```bash
curl -sSL https://raw.githubusercontent.com/Mihail007p/Gameigri/main/tools/restore.sh | bash
# или: git clone https://github.com/Mihail007p/Gameigri.git && cd Gameigri && node tools/test_game.js
```

Ничего уникального в рабочей области не хранится: код, журнал, тесты и скрипты — в репозитории.

## Публикация изменений

```bash
bash tools/gh_push.sh "feat: описание изменения"     # обычная публикация
bash tools/gh_push.sh --pages                        # и включить GitHub Pages
```

Скрипт сам скачает `gh` CLI при необходимости, **прогонит тесты** (упали — пуш отменяется),
выдаст одноразовый код для входа (https://github.com/login/device), закоммитит и запушит `main`.
Пароль не требуется, токен удаляется после пуша.
